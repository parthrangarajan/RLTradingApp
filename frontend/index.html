Reinforcement Learning Trading Simulator

Pick a stock, train a reinforcement learning agent that can buy, sell short, or stay in cash, then test it on a period it never saw while learning. Its results are compared with simple strategies so you can judge whether it adds any value.

Checking the connection to the server...

1Load market data

Choose one option. Option A downloads daily prices for any stock from Yahoo Finance. Option B uses a CSV file you downloaded yourself, for example from MarketWatch.

Option A: fetch by ticker

Option B: upload a CSV file

2Configure the run

Every field already holds a sensible default, so you can start straight away. Hover over any underlined label, or read the grey text under it, to learn what it means. Change anything you like before you start.

Interactive chart

      

        Hover over the price line to see your position and profit or loss on that day.
        Hover over a green or red triangle to see the details of that trade.
        Click a point on the price line to jump to that day in the day explorer below.
        Drag across the chart to zoom, and use the 1M, 3M, and All buttons to change the range.
      

      

      

        Green shading: you owned shares (long).
        Red shading: you owed borrowed shares (short).
        No shading: you held only cash (flat).
        Green up triangles: buys. Red down triangles: sells.
